Unknown Warming, Bayonne edition: daily temperature anomalies from a ground station

A Joy Division inspired plot of the daily temperature anomalies measured at Biarritz-Anglet (Bayonne), from Météo-France station data.

Author

Dimitri Masson

Published

October 18, 2026

Abstract

This is the local, ground-measured companion of Unknown Warming. Instead of the global ERA5 series, it uses the daily temperatures recorded at the Biarritz-Anglet weather station, the Météo-France station closest to Bayonne (the airport, about 5 km from the city centre).

Each line is one year. Its height shows how many days had a given temperature anomaly, that is the difference between the temperature of the day and the normal temperature of the same calendar day over a reference period. If the climate were stable, all the lines would pile up on the same hump; the drift of the whole distribution to the right is the local warming.

Two differences with the global plot: the anomalies are local (so each day is compared to the normal of its own calendar day, and the spread is much larger than for a global mean), and they are measured against 1991–2020 or 1961–1990, not against the 1850–1900 pre-industrial baseline, which cannot be derived from a single station.

Technical details

The processing is roughly divided into six steps:

  1. extracting the station series from the Météo-France open data (a Deno script)
  2. computing the normal temperature of each calendar day over the reference period
  3. subtracting it from every day to get the anomalies
  4. counting the anomalies per year
  5. applying a Gaussian blur to smooth out the graph
  6. offsetting the curve of each year to produce the Joy Division effect

Getting the data

Météo-France publishes its climatological data under the Etalab Open Licence 2.0 on data.gouv.fr. The daily files are distributed by département and by period, as compressed CSV files with all the stations of the département and many parameters (precipitation, temperature, wind). The file names change every year, and each is a few hundred MB once unzipped, so the extraction is done once, offline, by fetch-bayonne.ts:

deno run --allow-net --allow-write fetch-bayonne.ts          # writes bayonne_daily_temperature.csv
deno run --allow-net fetch-bayonne.ts --list                 # check the candidate stations first

The script asks the data.gouv.fr API for the département 64 files, streams them, keeps the stations whose name matches Biarritz, Bayonne or Anglet, prints a summary of each (first and last day, number of complete years) and writes the chosen one to a small CSV. Use --station <NUM_POSTE> to force another station, and --variable tm to use the mean of the hourly temperatures instead of the default (TN+TX)/2.

NoteDaily mean definition

By default the daily mean is (TN+TX)/2, which exists whenever both extremes were recorded, and is therefore the most consistent definition across the whole record. The mean of the hourly temperatures (TM) is available for a shorter period, and the two differ slightly. Mixing them in the same series would create artificial steps in the anomalies.

The CSV starts with comment lines (starting with #) describing the source and the station, which are removed before parsing, as in the original plot.

rawText = FileAttachment("./bayonne_daily_temperature.csv").text()

stationMeta = {
  const meta = {};
  for (const line of rawText.split("\n")) {
    const m = /^#\s*(\w+):\s*(.*)$/.exec(line);
    if (m) meta[m[1]] = m[2];
  }
  return meta;
}

rawData = d3.csvParse(
  rawText.split("\n").filter(l => l.trim() && !l.startsWith("#")).join("\n"),
  d => ({
    year: +d.date.slice(0, 4),
    slot: slotOf(d.date),
    t: d.tmean === "" ? NaN : +d.tmean
  })
).filter(d => Number.isFinite(d.t))

placeName = "Bayonne"
sourceNote = `Météo-France, station ${stationMeta.station ?? "Biarritz-Anglet"}`

Computing the daily normal

Unlike the global series, a single place has a strong seasonal cycle, so an “anomaly” must be measured against the normal temperature of that calendar day. For every day of the year we average the temperature over the reference period (1991–2020 by default). The window is a few days wide (±3 by default, adjustable in the sidebar) so that the normal is not a noisy single-day average, but narrow enough not to flatten the seasonal peaks.

Dates are mapped to a “slot” in a leap-year calendar, so that 29 February has a slot of its own and every later date keeps the same slot in all years.

CUM = [0, 31, 60, 91, 121, 152, 182, 213, 244, 274, 305, 335]
slotOf = iso => CUM[+iso.slice(5, 7) - 1] + +iso.slice(8, 10) - 1

climatology = {
  const [b0, b1] = baseline.split("-").map(Number);
  const sum = new Float64Array(366), n = new Float64Array(366);
  for (const d of rawData) {
    if (d.year >= b0 && d.year <= b1) { sum[d.slot] += d.t; n[d.slot]++; }
  }
  const raw = Array.from(sum, (s, i) => n[i] ? s / n[i] : NaN);
  return raw.map((_, i) => {                       // circular moving average, ±normalWindow days
    let a = 0, c = 0;
    for (let k = -normalWindow; k <= normalWindow; k++) {
      const v = raw[(i + k + 366) % 366];
      if (!Number.isNaN(v)) { a += v; c++; }
    }
    return c ? a / c : NaN;
  });
}

Anomalies

The anomaly of a day is its temperature minus the normal of its slot. Only complete years (at least 330 days with data) are kept, which also drops the current, unfinished year.

anomalies = rawData
  .map(d => ({year: d.year, slot: d.slot, anomaly: d.t - climatology[d.slot]}))
  .filter(d => Number.isFinite(d.anomaly))

byYear = d3.group(anomalies, d => d.year)
years = [...byYear].filter(([y, v]) => v.length >= 330).map(([y]) => y).sort(d3.ascending)
minYear = years[0]
maxYear = years[years.length - 1]

yearStats = years.map(y => ({
  year: y,
  n: byYear.get(y).length,
  mean: d3.mean(byYear.get(y), d => d.anomaly),
  reference: maxYear - y
}))
yearStatsMap = new Map(yearStats.map(d => [d.year, d]))
labelledYears = yearStats.filter(d => d.year % 5 === 0 || d.year === maxYear)

Grouping the anomalies by year

For each year we count the days falling in each bin of the anomaly. The bins are 0.5 °C wide, and the horizontal range adapts to the climate of the place: a continental winter swings much more than the Basque coast, so the range is set from the 99.9th percentile of the absolute anomalies, rounded up to a multiple of 4 °C (between ±8 and ±32 °C).

binWidth = 0.5
limit = {
  const keep = new Set(years);
  const a = anomalies.filter(d => keep.has(d.year)).map(d => Math.abs(d.anomaly)).sort(d3.ascending);
  return Math.min(32, Math.max(8, Math.ceil(d3.quantileSorted(a, 0.999) / 4) * 4));
}
length = Math.round(2 * limit / binWidth)
indexF = x => Math.max(0, Math.min(length - 1, Math.floor((x + limit) / binWidth)))
indexF_1 = i => -limit + (i + 0.5) * binWidth

counts = new Map(years.map(y => {
  const a = new Float64Array(length);
  for (const d of byYear.get(y)) a[indexF(d.anomaly)]++;
  return [y, a];
}))

xStep = limit <= 12 ? 2 : limit <= 20 ? 4 : 8
xTicks = d3.range(-Math.floor(limit / xStep) * xStep, limit + 1, xStep)

Smoothing the data with a Gaussian blur

As in the original plot, the counts are smoothed with small binomial kernels (a discrete approximation of a Gaussian), keeping only the positive side of each kernel. With 0.5 °C bins, the default factor 2 corresponds to a standard deviation of about 0.5 °C.

kernels = [
      [1],
      [2, 1],
      [6, 4, 1],
      [20, 15, 6, 1],
      [70, 56, 28, 8, 1],
    ];
kernelVisu = kernels.flatMap( (kernel, i) =>
      kernel.flatMap( (e, j) => (j == 0)? Array(e).fill( {i, j } ) : Array(e).fill( [{i, j }, {i, j: -j} ]) ) )
      .flat()

Plot.plot({
  marks: [
    Plot.barY(kernelVisu,
      Plot.binX({y: "proportion-facet"},
        { x: "j", fx: "i", stroke: "black", fill: "black"})),
    Plot.axisY({label: "Weight", tickFormat: "%"})
  ],
  grid: true,
  x: { tickFormat: (d) => d == 0 ? "0" : Math.floor(+d), label: "Kernel Offset" },
  fx: { label: "Kernel Size", anchor: "bottom" },

The smoothed counts are turned into a share of the days of the year, then scaled so that the tallest ridge of the whole chart is ridgeHeight rows high. This keeps the plot readable whatever the climate (a narrow distribution gives a high, thin hump, a broad one a low, wide hump), and each ridge is finally offset by its year.

joyData = {
  const kernel = kernels[smoothFactor];
  const smooth = y => {
    const c = counts.get(y), n = byYear.get(y).length;
    return Float64Array.from(c, (_, i) => {
      let result = 0, weight = 0;
      for (let j = 1 - kernel.length; j < kernel.length; j++) {
        const m = i + j;
        if (m >= 0 && m < length) {
          const k = kernel[Math.abs(j)];
          result += c[m] * k;
          weight += k;
        }
      }
      return result / weight / n;   // share of the days of the year
    });
  };
  const dens = years.map(y => ({y, s: smooth(y)}));
  const peak = d3.max(dens, d => d3.max(d.s));
  return dens.flatMap(({y, s}) => {
    const st = yearStatsMap.get(y);
    return Array.from(s, (v, i) => ({
      year: y,
      anomaly: indexF_1(i),
      count: v,
      height: st.reference + v / peak * ridgeHeight,
      reference: st.reference,
      yearMean: st.mean
    }));
  });
}

Colouring the years

Colouring each year by its mean anomaly shows the warming at a glance. A standard diverging scale such as RdYlBu is pale yellow in the middle, which is nearly invisible on a white page (its contrast ratio against white is about 1.1:1). The interpolator below therefore caps the lightness of every colour in the perceptual Lab space, keeping hue and chroma: the ends of the scale are untouched, the middle turns into a darker khaki that stays visible (about 2.7:1 at the default maximum lightness of 65). Lower the “Max lightness” slider for more contrast, raise it to 100 to get the plain RdYlBu back.

divergingInterpolator = t => {
  const c = d3.lab(d3.interpolateRdYlBu(1 - t));   // reversed: warm = red
  c.l = Math.min(c.l, maxLightness);
  return c.formatHex();
}
colorLimit = Math.max(0.5, Math.ceil(d3.max(yearStats, d => Math.abs(d.mean)) * 2) / 2)
colorScale = ({
  type: "diverging",
  pivot: 0,
  domain: [-colorLimit, colorLimit],
  interpolate: divergingInterpolator,
  label: "Yearly mean anomaly (°C)"
})

Limits of a station series

A station is a real measurement, but not a perfect one: the instruments, the shelter and the surroundings of the airport changed over the decades, and the definition of the daily extremes was modified over time, so part of the long-term drift can come from these changes rather than from the climate. Météo-France applies a climatological quality control, but the series is not homogenised in this visualisation. Years with fewer than 330 days of data are left out, which leaves visible gaps in the vertical axis.
